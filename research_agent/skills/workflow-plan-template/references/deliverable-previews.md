# Deliverable previews

Use one or two concrete, explicitly illustrative elements—not a mock report.

- Rating study: show a 2–3-row table using the real segments and scale labels.
- Key comparison: sketch the main chart with its actual axis/category names and
  plausible values labeled illustrative.
- Free text: show one short attributed response in the intended voice.
- Agent list: show two persona records in the actual output shape.
- Image study: identify the exact uploaded image and every question that will
  display it. Never silently substitute a prose description.

The preview exists so the user can correct the destination before execution.
Do not spend tokens inventing several alternative previews when the output is
already obvious.
