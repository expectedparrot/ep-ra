Mandatory post-run quality review after every survey or simulation run. Re-examines user inputs, study design choices, and actual results across four layers: (1) did the study answer what was actually asked, (2) design gaps in agents/questions/scenarios/model, (3) result anomalies and differentiation failures, (4) scope expansion opportunities. Produces a structured written assessment with ranked suggestions, presented to the user before proceeding to analysis or reporting.
